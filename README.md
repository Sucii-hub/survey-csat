# ⭐ Survey Kepuasan Pelanggan (CSAT)

Aplikasi web formulir *Customer Satisfaction Score* (CSAT) interaktif yang dirancang untuk mengukur tingkat kepuasan pelanggan dan mengumpulkan umpan balik (*feedback*) bagi evaluasi bisnis.

---

## 🚀 Fitur Utama
- **Penilaian Visual Interaktif:** Pilihan emoji rating (*Sangat Puas*, *Puas*, *Cukup*, *Kecewa*).
- **Pengumpulan Feedback:** Kolom catatan saran dan kritik pelanggan.
- **Ringkasan Skor CSAT:** Menghasilkan persentase nilai kepuasan secara langsung.
